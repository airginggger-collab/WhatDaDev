# WhatDaDev — контекст продукта для портфолио

> Назначение: блок «контекст» на странице кейса в портфолио. Читается за 5 секунд,
> отвечает на вопросы рекрутера до просмотра экранов.
> Дополняет [portfolio-story.md](portfolio-story.md) (там процесс и хронология, тут суть продукта).
> Источник фактов: `HANDOFF.md`, `00-overview.md`, `src/data/pricing.json`, `CLAUDE.md`.

## Лид

WhatDaDev это сайт компании, которая внедряет ELMA365 и продаёт коробочный продукт Coordo.
B2B-лидген без корзины: заявка уходит в CRM, счёт выставляют вручную.

## Таблица

| | |
|---|---|
| **Кто пользуется** | Комитет ЛПР в среднем бизнесе РФ и Казахстана: ИТ-директор, владелец процесса, финдиректор |
| **Платформа** | Веб, десктоп-first: закупку изучают за рабочим ноутбуком. Статика Astro, текст в HTML ради индексации, мобильная вёрстка обязательна |
| **Тип продукта** | Не екомерс и не админка: лидген-сайт на 70 страниц. Внутри кабинет на Sveltia CMS, чтобы менеджер правил тексты без разработчика |
| **Задача бизнеса** | Две равные воронки, услуги и продукт 50/50, и органика выше конкурентов в Яндексе. Coordo стоит 990 000 ₽ разово, цикл сделки длинный |
| **Моя роль** | Единственный дизайнер и разработчик: стратегия, структура, тексты, дизайн-система, код, деплой |
| **Что улучшено** | Старый WordPress продукт не продавал. Стало 70 страниц, 20 статей и глоссарий, издательская типографика вместо дефолтных Inter и indigo, 16 решений в ADR |

## Оговорки при использовании

- **Цена меняется.** В `pricing.json` живут база 990 000 ₽ и акция 690 000 ₽ со сроком до 31.07.2026,
  срок прошёл. Для портфолио либо берём базу, либо убираем сумму: смысл строки не пострадает.
- **70 страниц считаются вместе с 404.** Если нужна чистая цифра контента, пишем 69.
- Формулировки в таблице проходят чек-лист текста из [21-quality-checklists.md](21-quality-checklists.md):
  без длинного тире, без ИИ-лексики, каждая цифра с источником.
